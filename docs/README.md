# docs/

Written material supporting both the operational platform and its portfolio framing.

- **`architecture/`** — system design notes and diagrams (cluster topology, networking, data flow).
- **`hardware/`** — node inventory, specs, and bootstrap history for each physical machine.
- **`decisions/`** — architecture decision records (ADRs): what was chosen, alternatives considered, and why (e.g. GPU purchase evaluations).
